## 🚀 Get Started (Vercel / Web Hosted)

1. **Clone the Repo**
   ```bash
   git clone https://github.com/michaeldubu/saaam_studio-nl
   cd saaam_studio-nl
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Locally**
   ```bash
   npm run dev
   ```

4. **Deploy on Vercel**
   - Drag-and-drop to [vercel.com](https://vercel.com)
   - Or use:
     ```bash
     vercel
     ```
